# ATK FOA 5.1.2 Matrix Decoder – Design, Configuration, and Rationale

### Purpose
The ATK FOA 5.1.2 Matrix Decoder converts First-Order Ambisonics (FOA) B-format (`W`, `X`, `Y`, `Z`) into a 7.1-channel speaker layout with height channels: Front Left (FL), Front Right (FR), Centre (C), Rear Left (RL), Rear Right (RR), LFE, Top-Front Left (TFL), and Top-Front Right (TFR). The decoder supports multiple lower-ring decode modes (Equal, Focused, Four), adjustable height elevation, and output ordering for UHJ-Pi and Dolby layouts.

### Quick Start
- Insert the decoder on a FOA track with channel order `W, X, Y, Z`.
- Select output layout (`UHJ-Pi` or `Dolby`) to match your routing.
- Choose lower-ring mode: `Equal` (default), `Focused`, or `Four`.
- Adjust height elevation (default 45°) and trim to taste.
- Height HPF (default 80 Hz) prevents LF leakage to ceiling speakers.
- Defaults tuned for balanced spatial distribution and smooth height integration.

### Parameters

#### **Output layout** (`slider1`, default 0, options: {UHJ-Pi, Dolby})
- Selects the output channel order:
  - **UHJ-Pi**: FL, FR, C, RL, RR, LFE, TFL, TFR (channels 1–8)
  - **Dolby**: FL, FR, C, LFE, RL, RR, TFL, TFR (channels 1–8)

#### **Mode** (`slider2`, default 0, options: {Equal, Focus, Four})
- Sets the decode matrix for the lower ring (FL, FR, C, RL, RR):
  - **Equal**: Balanced distribution with equal energy across speakers. Centre receives minimal `W` (0.0) and moderate `X` (0.085).
  - **Focus**: Emphasizes centre channel with `W=0.2` and `X=0.16` for tighter front imaging.
  - **Four**: Eliminates centre channel (`W=X=Y=Z=0` for C), emphasizing the four corner speakers for wider soundstage.

#### **Centre trim (dB)** (`slider3`, default 0, range −60 to +12)
- Post-decode gain for the centre channel. Useful to balance dialogue or centre-heavy content.

#### **LFE trim (dB)** (`slider4`, default 0, range −60 to +12)
- Gain for the LFE channel. LFE is derived from FL+FR with a one-pole LPF (see LFE LPF below) and an additional +10 dB boost (≈3.16×) for level matching.

#### **LFE LPF (Hz)** (`slider5`, default 100, range 20–200)
- Low-pass filter cutoff for LFE extraction. Standard range is 80–120 Hz; 100 Hz is typical for Dolby compatibility.

#### **Height elevation (deg)** (`slider6`, default 45, range 30–90)
- Controls the elevation angle used for height speaker matrix calculation. The height matrix coefficients (`Y`, `Z`) are recalculated dynamically:
  - `Y` (left-right width) is held constant at 0.34 (matching front speakers at 30° elevation) to preserve horizontal separation.
  - `Z` (elevation) scales with elevation: `Z = √2 × sin(elevation)`.
  - `X` (front-back) is set to 0.0 to reduce directional similarity with front speakers.
  - `W` (ambient) is fixed at 0.408248 for upper hemisphere ambience.

#### **Height trim (dB)** (`slider7`, default 0, range −60 to +12)
- Post-processing gain for height speakers (TFL, TFR). Applied after HPF and gate (see below).

#### **Height HPF (Hz)** (`slider8`, default 80, range 20–3000)
- 2nd-order Butterworth high-pass filter applied to height speakers to prevent bass leakage to ceiling speakers. Default 80 Hz is typical for height channel bass management.

### Signal Flow (High Level)

1. **Input**: FOA B-format (`W`, `X`, `Y`, `Z`) with no processing applied upstream.
2. **Lower ring decode**: 5×4 matrix multiply for FL, FR, C, RL, RR (modes: Equal/Focus/Four).
   - Lower ring uses horizontal decode (`Z=0` in all matrices).
3. **Height decode**: 2×4 matrix multiply for TFL, TFR:
   - `W=0.408248` (ambient component)
   - `X=0.0` (no front-back directionality, reduces similarity to fronts)
   - `Y=±0.34` (left-right spatial width, constant regardless of elevation)
   - `Z` (elevation, scales with elevation slider)
4. **LFE extraction**: Sum of FL+FR passed through a one-pole LPF (100 Hz default), then gain-boosted by +10 dB.
5. **Height post-processing**:
   - 2nd-order Butterworth HPF (80 Hz default)
   - Height trim gain
   - Envelope-follower gate (based on `Z` magnitude) to mute height speakers when `Z≈0`
6. **Output routing**: Channel order set by output layout (UHJ-Pi or Dolby).

### Height Speaker Matrix Rationale

#### Historical Context
Earlier iterations used position-specific matrices with high `X` coefficients (e.g., `X=0.612`), making height speakers sound too similar to front speakers. With only two height speakers for 5.1.2, they must represent the entire upper hemisphere, not specific point sources.

#### Current Design Philosophy
- **W=0.408248 (ambient)**: Provides omnidirectional content for reverberant/diffuse upper-hemisphere material.
- **X=0.0 (removed)**: Eliminates front-back directionality that duplicated front speaker response.
- **Y=±0.34 (constant)**: Preserves left-right spatial width (e.g., left-side reverb favors TFL) regardless of elevation angle.
- **Z (scales with elevation)**: Primary elevation component. At 45°: `Z ≈ 1.0`; at 90° (overhead): `Z ≈ 1.414`.

#### Elevation Slider Behavior
The `Y` coefficient is intentionally held constant to maintain horizontal separation. If `Y` scaled with elevation, height speakers would collapse toward the centre as elevation increased, losing spatial width.

### Height Gate (Envelope Follower)

The decoder includes an envelope follower on `Z` magnitude to gate height speakers when `Z≈0`:
- **Attack**: 10 ms (fast response)
- **Release**: 50 ms (prevents gating on momentary dips)
- **Threshold**: 0.0001 (very low to avoid artifacts)
- **Minimum gain**: 0.0 (fully mutes when `Z` is absent)

This prevents residual `W/X/Y` content from leaking into height speakers when the source has no elevation component.

### LFE Channel

LFE is derived from the sum of FL+FR (not from `W` directly) to capture low-frequency content present in the front channels. A one-pole LPF at 100 Hz removes mid/high frequencies, and a +10 dB gain boost (×3.16) matches typical LFE level expectations.

### Testing and Listening Notes

- **Height speaker similarity to fronts**: Reduced `X` coefficient from 0.612 to 0.0 to eliminate front-speaker duplication.
- **Upper hemisphere representation**: Added `W` component (0.408248) so height speakers receive ambient/reverberant content.
- **Spatial width preservation**: Kept `Y` constant (0.34) regardless of elevation to maintain left-right separation.
- **Bass leakage to heights**: Implemented 2nd-order HPF at 80 Hz default to prevent LF content from reaching ceiling speakers.
- **Gate behavior**: Envelope follower (10 ms attack, 50 ms release) smoothly gates height channels when `Z=0` without artifacts.
- **Elevation adjustment**: Dynamic recalculation allows fine-tuning height position from 30° (forward) to 90° (overhead) while preserving spatial width.

### Theoretical Basis

#### First-Order Ambisonics Decoder Mathematics

For a speaker at azimuth θ (theta) and elevation φ (phi), first-order decoder coefficients are:

```
W = g₀                              (omnidirectional)
X = g₁ × cos(φ) × cos(θ)           (left-right)
Y = g₁ × cos(φ) × sin(θ)           (front-back)
Z = g₁ × sin(φ)                     (elevation)
```

Where:
- `g₀ = 1/√2 ≈ 0.707` (omnidirectional gain)
- `g₁ = √2 ≈ 1.414` (first-order gain)

#### Height Matrix Derivation

For Top-Front-Left (TFL) at typical position (±30° azimuth, variable elevation):
- **W**: Normalized ambient component = 0.408248
- **X**: `g₁ × cos(φ) × cos(±30°)` → Set to 0.0 to reduce front similarity
- **Y**: Held constant at 0.34 (matches front speakers at 30° elevation) to preserve horizontal separation
- **Z**: `g₁ × sin(φ)` → Scales dynamically with elevation slider

The normalization factor (0.577348) and matrix scaling follow ATK conventions for balanced energy distribution across the speaker array.

### Lower-Ring Modes

- **Equal**: Balanced distribution suitable for general use. Centre channel minimal.
- **Focus**: Emphasizes centre for dialogue/narration. Adds `W=0.2` and `X=0.16` to centre.
- **Four**: Removes centre entirely, emphasizing corner speakers for immersive/wider soundstage.

### Changelog Highlights (Design Evolution)

- **Height matrix redesign**: Reduced `X` from 0.612 to 0.0 to eliminate front-speaker similarity.
- **Added `W` component**: 0.408248 for upper hemisphere ambient content.
- **Elevation slider**: Dynamic `Z` recalculation with constant `Y` to preserve spatial width.
- **Height gate**: Envelope follower (10 ms attack, 50 ms release) gates on `Z` magnitude.
- **HPF on heights**: 2nd-order Butterworth at 80 Hz default to prevent bass leakage.
- **LFE extraction**: Changed from `W`-only to FL+FR sum for more accurate LF content.

### Practical Tips

- **Height elevation**: Start at 45° for typical top-front positioning. Increase toward 90° for overhead content.
- **Bass leakage**: If ceiling speakers receive unwanted LF, increase Height HPF (e.g., 100–120 Hz).
- **Height too quiet**: Use Height trim (+3 to +6 dB) or check that `Z` component is present in source.
- **Mode selection**: Use `Focus` for dialogue-heavy content; `Four` for wide, immersive soundscapes.
- **Layout compatibility**: Ensure your DAW routing matches the selected output layout (UHJ-Pi or Dolby).

### Integration with FOA Z Synthesis

This decoder is designed to work seamlessly with the **FOA Z Synthesis** plugin:
- Z Synthesis generates `Z` from lateral energy and applies ambience.
- The 5.1.2 Decoder receives the synthesized `Z` and routes it to height speakers.
- Height HPF (80 Hz default) in the decoder prevents bass leakage, complementing the synthesis plugin's spectral shaping.
