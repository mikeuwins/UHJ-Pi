PHJ Reaper Integration Guide
============================
Version: Rev G

1. Overview
-----------
This guide explains how to integrate the newly generated **PHJ (4‑channel UHJ)** encoder/decoder impulse responses into **Reaper**, using the **Ambisonic Toolkit (ATK)** convolution plugins. It assumes the verified kernels from `phj_build.py` have been installed into your ATK directory tree and verified via `phj_verify_all.py`.

### Kernel Source Location

The PHJ encoder and decoder kernels are distributed as part of the UHJ-Pi project and can be obtained from the following locations:

### Encoder Kernels
<https://github.com/mikeuwins/UHJ-Pi/tree/main/reaper/kernels/FOA/encoders/phj>

### Decoder Kernels
<https://github.com/mikeuwins/UHJ-Pi/tree/main/reaper/kernels/FOA/decoders/phj>

These directories contain the full set of FIR kernels across all supported sample rates and filter lengths.

---

2. ATK Folder Layout
--------------------
Ensure the following directory structure exists:

```
~/Library/Application Support/ATK/kernels/FOA/
├── encoders/
│   └── uhj/{fs}/{N}/0000/
│       ├── UHJ_L.wav
│       ├── UHJ_R.wav
│       ├── UHJ_T.wav
│       ├── UHJ_S.wav
│       └── UHJ_Q.wav
└── decoders/
    └── uhj/None/{N}/0000/
        ├── UHJ_W.wav
        ├── UHJ_X.wav
        ├── UHJ_Y.wav
        └── UHJ_Z.wav
```

These files were generated by `phj_build.py` and validated with `phj_verify_all.py`.  
Each `(fs, N)` pair (e.g. 44100/512) forms a matched encoder/decoder set.

---

3. Reaper Project Setup
-----------------------
### 3.1 Create three tracks
1. **Track 1 – B‑Format source**
   - Channels: 4  
   - Contains B‑Format signals (W, X, Y, Z)  
   - If starting from mono or stereo, insert an ATK FOA encoder here.

2. **Track 2 – PHJ Encoder**
   - Channels: 4  
   - Insert **ATK UHJ Encoder (PHJ)** plugin.  
   - Select the correct `(fs, N)` set (e.g. 44100/512).  
   - Routing: Track 1 → Track 2 (send all 4 channels).

3. **Track 3 – PHJ Decoder**
   - Channels: 4  
   - Insert **ATK UHJ Decoder (PHJ → FOA)**.  
   - Select the same `N` as the encoder.  
   - Routing: Track 2 → Track 3 (send all 4 channels).

This forms a full loop:  
**[FOA] → [PHJ Encode] → [PHJ Decode] → [FOA′]**

---

4. Verifying Correct Operation
------------------------------
### 4.1 Round‑trip null test
1. On Track 3, invert the polarity of all 4 channels (use **JS: Utility/Phase Adjust**).  
2. Add a 4‑ch send from Track 1 (original FOA) to Track 3 (decoded FOA inverted).  
3. Sum both tracks — you should hear **near‑silence (null)**.  
   - A residual level < –60 dBFS is normal.  
   - If not: check channel counts and confirm both plugins use the same `(fs, N)` set.

### 4.2 Impulse‑centre check
- Drop a Dirac impulse (single‑sample click) on Track 1.  
- Observe Track 2 and 3 outputs: all impulses should appear centred (within ±0.5 samples of N/2).  
- This confirms time alignment and correct convolution delay.

---

5. Monitoring Stereo BHJ Compatibility
--------------------------------------
To audition stereo‑compatible output:

1. Create a **Stereo Monitor** track (2 channels).  
2. Add a receive from Track 2 (PHJ encoder) using **only channels 1–2 (L/R)**.  
3. Route to your main speakers or headphones.

This reproduces the stereo UHJ (BHJ) subset exactly as described by Gerzon (1980).

---

6. Using the 3‑channel Variants (THJ, SHJ)
------------------------------------------ **THJ**: use `L,R,T` (omit Q).  
- **SHJ**: use `L,R,S` (omit Q).  
  The `S` channel is a low‑passed version of `T` (~0.09·fs ≈ 4 kHz).

If your ATK plugin exposes THJ/SHJ modes, select accordingly.  
Otherwise, mute the unused channel manually and test via direct playback.

---

7. Latency
----------
Each convolution introduces a group delay of N/2 samples; encoder + decoder ≈ N.  
Reaper applies **Plugin Delay Compensation (PDC)** automatically.  
At 44.1 kHz, N = 512 → ≈ 11.6 ms round‑trip.

---

8. Common Issues
----------------
| Symptom | Likely cause | Fix |
|:--|:--|:--|
| No output / wrong channels | Track not set to 4 ch | Set “Track Channels → 4” |
| Imaging offset / poor null | Encoder/decoder N mismatch | Use identical N for both |
| Missing kernels | Wrong ATK root path | Verify `~/Library/Application Support/ATK` |
| S not matching T | Old IRs | Re‑run `phj_build.py` with `--force` |

10. Next Steps
--------------
When the Reaper integration is confirmed, the same IRs can be loaded into **SuperCollider** using `Buffer.read` and `Convolution2`.  
This will complete the cross‑platform workflow linking ATK, Reaper, and the UHJ‑Pi decoding chain.
